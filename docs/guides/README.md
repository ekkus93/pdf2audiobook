# User and contributor guides

[Home](../../README.md)

Start with [installation and your first audiobook](getting-started.md), then use
[configuration](configuration.md) to save the settings you want for every run. Commands in
these guides assume you are in the repository root and run the CLI through `uv run`.

| Guide | Use it to |
|---|---|
| [Installation and first audiobook](getting-started.md) | Install prerequisites and follow the illustrated conversion walkthrough |
| [Configuration](configuration.md) | Create a config file, understand overrides and troubleshoot settings |
| [CLI reference](cli.md) | Look up commands, exit codes, batch conversion and progress output |
| [Voices and speech](voices.md) | Listen to voice samples, select a model and adjust pronunciation |
| [LLM assistance](llm.md) | Set up Ollama and manage context, timeouts, budgets and privacy |
| [Editing and review](editing-and-review.md) | Review chapters, protect edits and recover interrupted updates |
| [Audio verification and repair](audio-verification.md) | Check synthesized audio and repair individual chapters |
| [Development and validation](development.md) | Run lint, type checks, tests and opt-in provider smoke checks |

The [desktop guide](../../desktop/README.md) covers the Linux GUI and installers.
The [maintainer guide](../MAINTAINER_GUIDE.md) describes implementation contracts;
specifications and historical acceptance records live in the parent `docs/` directory.
